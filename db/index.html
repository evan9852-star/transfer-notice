저장할 연락처 0명

연락처 파일을 받은 뒤
  1. 맥: 파일을 두 번 누르면 연락처 앱에 들어가고, 아이클라우드로 휴대폰에도 들어갑니다. 아이폰은 파일을 열고 모두 추가.
  2. 카카오톡 톱니바퀴 → 환경설정 → 친구 → 동기화. 휴대폰 카톡에서도 친구 새로고침을 하면 빨리 뜹니다.
  3. 카톡 친구에서 DB로 찾아 '카톡 이름 확인' 표시가 붙은 사람의 카톡 이름을 봅니다.
  4. 아래 장부에서 이름을 고치고 고친 사람만 연락처 파일을 받아 다시 엽니다. 연락처 앱이 같은 사람이라고 물으면 '업데이트'를 고르세요.
