# 이관고객 안내문자

이관고객 엑셀을 넣고 고객을 고르면, 전화 전에 보낼 안내 문자가 고객별로 만들어지는 페이지입니다.

- 주소: https://evan9852-star.github.io/transfer-notice/
- 엑셀은 브라우저 안에서만 읽습니다. 서버로 올라가지 않습니다.
- '카톡 나에게 보내기'를 누르면, 카카오로 로그인한 본인의 '나와의 채팅'으로만 문자가 들어갑니다.

## 쓰는 법
1. 오른쪽 위 **카카오 로그인** (처음 한 번 동의)
2. 엑셀 파일을 끌어 놓기 — '성명'·'계약명' 머리글이 있으면 됩니다
3. 매니저 이름과 통화 일시 입력
4. 보낼 고객 고르기
5. **카톡 나에게 보내기** 또는 고객별 **문자 복사**

## DB 고객 관리 (`/db/`)
- 주소: https://evan9852-star.github.io/transfer-notice/db/
- 단장님이 카톡으로 보낸 DB 목록(`지역  이름  번호  담당`)을 붙여넣으면 `DB 이름 (26.11)` 같은 저장 이름을 붙여 연락처 파일(.vcf) 하나로 만듭니다.
- 아이폰에서 파일을 열면 '모두 추가', 맥은 두 번 눌러 연락처 앱으로. 받은 DB는 아래 장부에 쌓이고 엑셀로 받을 수 있습니다. 장부에서 고른 사람마다 OT 안내문자(명함·홍보 사진 포함)를 만듭니다.

## TAMS 멘티 관리 (`/tams/`)
- 주소: https://evan9852-star.github.io/transfer-notice/tams/
- 캠리 터치(카톡 붙여넣기): 카톡으로 받은 DB 줄(시간·이름·번호·메일·학교·동의·학년·나이·전공)을 붙여넣으면 번호를 010으로 고치고 연락처 파일(.vcf)과 A안 터치 문자를 만듭니다.
- 캠리 터치(직접 쓰기): 종이 신청서를 보고 이름·번호를 넣으면 연락처 파일과 터치 문자(내가 발표한 캠리면 B안)를 만듭니다.
- 멘티 장부: 터치 / 지원서 받음 / 첨삭함 / 실장님 제출 체크, 엑셀·백업.
- 지원서: 기본 양식(`tams/application.docx`) 파일 받기, 카톡 창으로 끌어 놓기. 새 기수 지원서를 넣으면 파일 속 'O기'를 읽어 기수와 터치 문자가 바뀝니다.
